# AI Agent & Developer Skill: Project Initialization Protocol (AFT & BPT)

> **Amaç:** Makinede yeni bir geliştirme projesi başlatılırken Nix/Devenv izolasyonu ve AI context standartlarına uyumu sağlayan protokol.

## 🚀 Proje Başlatma Betikleri

### 1. AFT (Agentic Framework Template)
Full-Stack Next.js 16 + React 19 + AI Context projeleri için:
```bash
./scripts/aft-init.sh proje-adi
```

### 2. BPT (Base Polyglot Template)
Python, Node, Rust, Go, Java veya Minimal dil şablonları için:
```bash
./scripts/bpt-init.sh proje-adi [python|node|rust|go|java|minimal]
```
