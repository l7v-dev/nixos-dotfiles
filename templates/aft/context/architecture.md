# Architecture - AFT

## Klasör Düzeni
- `src/app`: App Router routeları, layoutlar ve global stiller.
- `src/components/ui`: Atomik ve bağımsız UI parçaları.
- `src/components/common`: Header, Navbar ve Footer gibi sayfa bileşenleri.
- `src/lib`: Utility fonksiyonları ve API fetcher katmanı.
- `src/config`: Uygulama ve site ayarları.
- `src/types`: Ortak TypeScript tip tanımları.
- `prisma`: Veritabanı şeması ve migration yapılandırması.
